# 名詞小辭典

技術報告裡用到的名詞，用一兩句白話解釋。不需要先讀這一頁；各篇第一次用到時也會說明，這裡是方便回頭查。

## 拍照與相機

| 名詞 | 白話 |
| --- | --- |
| T-pose | 人站直、雙臂向兩側平舉，像字母 T。四肢彼此分開，最容易從照片分辨形狀。 |
| 正交投影 | 一種「沒有近大遠小」的拍法：所有視線互相平行。同一個東西不管離相機多遠，在照片上一樣大。工程圖的三視圖就是正交投影。 |
| 透視 | 一般相機和人眼的拍法：視線從一點散開，近的東西比較大。 |
| 方位角 | 相機繞著人物轉到哪裡。0° 是正面，90° 是人物的左側，180° 是背面。檔名裡的 `045deg` 就是 45°。 |
| 俯角、仰角 | 相機抬高往下看是俯角，放低往上看是仰角。 |
| 特寫 | 只拍頭部的照片，放大成全身照的 4 倍，臉的細節才夠。 |
| 一圈（環） | 同一個高度繞人物拍的 8 張，每 45° 一張。 |
| 完美照片 | 不是 AI 畫的，而是拿一個已知的 3D 人物用電腦渲染出來的 33 張。保證是同一個人、同一台相機，用來量程式自己的誤差。 |
| 渲染 | 讓電腦依照 3D 模型和相機的位置，算出一張圖。 |

## 形狀

| 名詞 | 白話 |
| --- | --- |
| 去背 | 把照片裡的人物和背景分開。 |
| 剪影 | 去背之後，人物所在的那一塊：只有「是人」和「不是人」，像影子。 |
| 外殼（剪影外殼） | 用很多張剪影雕出來的形狀：每張剪影都說「這裡是人」的地方留下，其餘削掉。它一定包住真正的身體，但凹進去的地方雕不出來。 |
| 體素 | 立體的像素：把空間切成一格一格的小方塊（這裡每格 4 mm），每格記「是身體」或「不是」。 |
| 網格 | 用很多小三角形拼成的表面，3D 模型的外皮。三角形的角叫頂點。 |
| 特徵點 | 臉上有固定意義的點，例如鼻尖、眼角、嘴角。軟體（MediaPipe）能在照片上自動找出 468 個。 |

## 顏色

| 名詞 | 白話 |
| --- | --- |
| 貼圖 | 包在網格外面的那張圖，決定模型每個地方是什麼顏色。 |
| UV | 把立體的表面「攤平」成一張圖的對應方式，像把地球儀攤成世界地圖。 |
| 烘焙 | 把照片上的顏色搬到貼圖上：模型表面每一點，去看哪幾張照片拍得到它，取那裡的顏色。 |
| 重影 | 同一個東西（例如眼睛）在貼圖上出現兩次，稍微錯開。 |
| 接縫 | 貼圖上一條不該有的邊界，兩邊的顏色來自不同的照片。 |
| 無光照 | 模型直接顯示貼圖的顏色，不再另外打光。 |
| 色差（ΔE） | 兩個顏色看起來差多少的數字。大約 2 以上，並排時肉眼分得出來。 |

## 讓模型動起來

| 名詞 | 白話 |
| --- | --- |
| 骨架 | 藏在模型裡的一組「骨頭」，轉動骨頭就能擺姿勢。 |
| 權重（蒙皮） | 表面每一點跟著哪幾根骨頭動、各跟多少。權重錯了，擺姿勢時皮膚會被扯到不該去的地方。 |
| 模板 | 別人做好的、有關節和手指的通用人體（這裡用 MakeHuman）。把它變形成這個人，就不用從零做骨架。 |
| GLB | 一種 3D 模型的檔案格式，網格、貼圖、骨架都包在一個檔裡，App 和遊戲引擎可以直接讀。 |
| Morph target | 預先存好的另一個形狀（例如微笑的臉），可以和原本的形狀之間漸變。表情通常靠它。 |

## 檢查與驗收

| 名詞 | 白話 |
| --- | --- |
| 關卡 | 流程中的檢查站，共四道：照片、烘焙前、模型檔、成品。有一項失敗就停。 |
| PASS／WARN／FAIL | 通過／提醒（請人看一下）／失敗（不能交付）。 |
| 門檻 | 一項檢查量到多少算通過、多少算失敗的那條線。 |
| 剪影差異 | 把成品模型投回原來的照片，模型的輪廓和照片的輪廓不重疊的面積，佔照片輪廓的百分比。越小越像。 |
| 重合度（IoU） | 兩個形狀疊在一起，重疊的面積除以合起來的面積。完全一樣是 1。 |

## 專案裡的稱呼

| 名詞 | 白話 |
| --- | --- |
| 執行者 | 負責生圖、重畫、跑流程的 AI（ChatGPT、Gemini）。Claude 負責維護規則和程式。 |
| issue、PR | GitHub 上的「問題回報」與「修改提案」。執行者卡住時發 issue；改程式用 PR。 |
| R17、v015 這類代號 | 某個執行者做的第幾版。ChatGPT 的寫成 R（round），Gemini 的寫成 v。 |
| luna | 完美照片用的 3D 人物之一：別人做好的、公開授權的女性模型（Yoga2 的教練）。和這條流程無關，所以是「人長什麼樣」的對照。 |
| synth、synth1 | 完美照片用的另一個 3D 人物：這條流程早期做出來的成品，拿回來當測試模型。它的臉是平的（當時還不會補臉的起伏）。之後若再凍結新的成品當測試模型，依序叫 synth2、synth3；舊的保留，數字才能前後比較。沒寫編號的 synth 就是 synth1。 |
| 完美照片 | 用已知的 3D 人物、照規格的相機「拍」出來的 33 張照片。它們彼此完全一致，所以每一項檢查都該通過；重建出來的結果也可以直接和那個 3D 人物比。 |
| 準確的輪廓、上限 | 給 AI 當畫布的兩種線。準確的輪廓：照著填就對（例如背面的輪廓是正面的左右翻轉）。上限：只保證人在線裡面，照著填會太胖（例如外殼的投影）。 |
